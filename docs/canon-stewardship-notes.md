# Canon Stewardship Notes

This document records public-facing consistency decisions for the repository.

## Naming

The current public ecosystem name is **Abracadabracadoo**.

Some historical drafts use **Abracadabradoo**. Those names are preserved in original filenames, legal/provenance documents, and source-derived text where changing them could obscure history. Current-facing README and navigation language should prefer **Abracadabracadoo**.

**Abracadoo.app** is the app / implementation shorthand.

## Legacy project names

Older drafts may mention **DeepTrust** or **Dialogica**. These are retained where they are part of source-document provenance or sibling protocol history. Current public positioning should avoid presenting DeepTrust as an active project name.

## Addendum numbering

The source corpus contains two historical documents labeled Addendum V. The repository preserves both without overwriting either:

- `addendum-05a-witness-readable-controlled-verifiability.md`
- `addendum-05b-affective-signaling-and-consent-resonance.md`

Long-term cleanup should prefer stable registry IDs over relying exclusively on Roman-numeral addendum titles.

## Status normalization

Canonical Markdown files use a normalized `status` field such as `stable`, `draft`, `experimental`, `legacy`, `roadmap`, `conceptual`, `training`, `whitepaper`, or `legal-draft`.

Where useful, the original source status is retained in `original_status`.
