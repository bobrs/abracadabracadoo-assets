# Contributing

Contributions are welcome as forks, issues, pull requests, diagrams, implementation notes, review comments, or alternate explanations.

This repository is intended to remain:

- Legible to humans
- Friendly to implementers
- Honest about draft status
- Consent-aware in its use of examples, identities, and claims

## Preferred contribution types

- Typo and clarity fixes
- Diagrams explaining protocol flows
- Implementation notes from builders
- Security review notes
- Alternative examples and use cases
- Suggestions for canon numbering and terminology cleanup

## Document format

Markdown is preferred for all canonical protocol documents.

Use stable headings, plain language where possible, and avoid embedding generated artifacts directly in source documents.
