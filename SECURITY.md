# Security Policy

The documents and implementations associated with this repository are experimental unless a document explicitly states otherwise.

This repository includes cryptographic, authentication, consent, and trust-protocol materials. They are published for inspection, discussion, prototyping, and reference implementation work.

## Production-use caution

Do not rely on these specifications or related code for production security-critical use without independent review, implementation testing, and cryptographic audit.

## Reporting issues

For security-sensitive concerns, avoid publishing exploit details in a public issue before maintainers have had a chance to review. Prefer contacting the project maintainer directly through the contact information provided in the active project repository or website.

## Scope

This repository is primarily an assets and specifications shelf. Application-code vulnerabilities should be reported against the relevant implementation repository, such as `abracadoo-code`, unless the vulnerability concerns a specification flaw or protocol design issue.
