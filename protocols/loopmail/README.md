# Loopmail

Loopmail is a context-aware, relationship-specific email concept that treats communication as intentional loops rather than an infinite default inbox.

Instead of a single static address for all interactions, Loopmail uses purpose- or relationship-specific addresses, first-contact consent, loop activation, loop memory, and optional tone/scalar modulation.

## Relationship to the stack

Loopmail is an application-layer expression of loop-native communication. It translates consent, context, tone, and boundary-setting into a familiar email-like interface.
