# Trust Interoperability Standard

The Trust Interoperability Standard (TIS) is published here as a sibling standard layer for consent-native and trust-native systems.

TIS provides portable semantics for trust offers, identity assertions, consent states, reputation signals, dialogue turns, dialogue threads, semantic graph mappings, and agent-facing trust exchange APIs.

## Why TIS belongs here

Abracadabracadoo provides consent-native communication and proof structures. HumanKey provides relationship-sized authentication. TIS provides the interoperable semantic layer that allows agents, applications, and protocols to describe what a trust event *means* across systems.
