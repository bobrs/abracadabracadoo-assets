# Protocols

Canonical public Markdown documents for the Abracadabracadoo protocol family.

## Core

- Abracadabracadoo Protocol Specification
- Abracadabra legacy reference specification

## Addenda

Addenda extend the core protocol into declarations, nested loops, witnesses, subjective time, deniability, forgetting, and evaluation governance.

## Extensions

Extensions describe optional practical layers such as consent confirmation loops and blockchain-backed verification.

## Roadmap

FractalIdentity is currently treated as a roadmap layer for the app: context-sized selfhood, plural channels, roles, aliases, and boundaries for future versions of Abracadoo.app.
