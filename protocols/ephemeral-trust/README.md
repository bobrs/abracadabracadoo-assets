# Ephemeral Trust Papers

This folder contains the Ephemeral Trust Papers, a six-part conceptual series on situational, consent-based trust as a dynamic substrate for relationships, culture, governance, and protocol design.

Ephemeral trust is treated here as the immediate, contextual, bidirectional trust that can form without institutional mediation and dissolve without penalty when the shared context ends.

## Papers

1. [Ephemeral Trust: Definition & Dynamics](01-definition-and-dynamics.md)
2. [Ephemeral Trust as a Portable Anchor](02-portable-anchor.md)
3. [The Immune System of Consent-Based Systems](03-immune-system-of-consent-based-systems.md)
4. [Cultural Infrastructure for Ephemeral Trust](04-cultural-infrastructure.md)
5. [Ephemeral Trust in Economic and Political Models](05-economic-and-political-models.md)
6. [The Cosmology of Trust](06-cosmology-of-trust.md)

## Relationship to the stack

Ephemeral trust is a conceptual foundation for HumanKey, Abracadabracadoo, TIS, and future FractalIdentity work. It describes the human-scale trust dynamics that the technical protocols attempt to preserve rather than replace.
