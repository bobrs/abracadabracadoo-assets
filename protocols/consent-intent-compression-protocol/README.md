# Consent-Intent Compression Protocol (CICP)

This folder collects the **Consent-Intent Compression Protocol (CICP)** and adjacent loop, glyph, ritual, key-derivation, and field-infrastructure documents.

CICP functions as a bridge layer between symbolic intent, consent-bearing loops, ritual/physical infrastructure, and machine-readable compression of meaning. It sits near Loop Training, Loopwise Philosophy, FractalIdentity, HumanKey, and Abracadabracadoo rather than replacing any one of them.

- CICP core document
- Symbolic Loop Development Language Specification (SLDLS)
- LOOPtLOOP implementation and field infrastructure documents
- Synaptic Dyad Protocol and Synaptic Trust Filters
- Rosetta Loop Specification
- Loop Substrate / Tensor / Projection materials
- Field Echo and temporal architecture notes
- Glyph, wave-state, loop-equivalence, and quantum-loop ontology documents
- Ritual loop token / NFC / ESP32 materials
- Application briefs for toys, gaming, Web3, healthcare, mental wellness, and presence platforms
- FractalIdentity Tree materials under [`fractalidentity-tree/`](fractalidentity-tree/)
